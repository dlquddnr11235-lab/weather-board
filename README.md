# 현장 일정 날씨판

오늘 현장 일정과 지역별 날씨를 한 화면에서 보고, 날씨 때문에 주의 · 중지를 검토할 일정을 표시합니다. (교육용 가상 데이터)

## 여는 법
- 인터넷 : Vercel 등의 배포 주소로 엽니다. (배포 후 주소를 여기에 적기)
- 내 PC : `index.html`을 더블클릭해 화면을 열 수 있습니다. 브라우저가 JSON 파일 읽기를 차단하면 `배포 주소로 열어 주세요`가 표시됩니다.

## 파일
| 파일 | 역할 |
|---|---|
| index.html | 화면 구조 |
| style.css | 디자인 |
| logic.js | 판단 규칙 · API 주소 생성 · 응답 해석 |
| app.js | 화면 동작 |
| data/tasks.json | 기본 가상 일정 6건 |
| PRD.md | 무엇을 · 왜 만드는지 |
| CLAUDE.md | AI가 지킬 작업 규칙 |
| .gitignore | GitHub에 올리지 않을 파일 목록 |

## 일정 데이터
- `app.js`가 `data/tasks.json`을 먼저 읽은 뒤, 브라우저의 `wx_added`에 저장된 추가 일정을 뒤에 붙입니다.
- 기본 일정은 JSON에서만 관리합니다. 화면에서 추가한 일정만 브라우저에 저장하며 JSON 파일은 바꾸지 않습니다.
- 로딩 중에는 추가 버튼이 잠시 비활성화됩니다. JSON 읽기에 실패해도 저장된 추가 일정은 표시합니다.
- 브라우저에 저장한 일정은 같은 브라우저의 같은 배포 주소에서 유지됩니다. 내 PC 파일 주소와 배포 주소의 저장 공간은 서로 다릅니다.

## 오늘 날씨 (F-04)
- 세종 · 대전 · 태안 · 보령의 대표 좌표로 Open-Meteo API를 호출합니다. 키는 필요 없으며 인터넷 연결이 필요합니다.
- 한국 시간(Asia/Seoul)의 오늘 하루 최고 기온, 최대 풍속(m/s), 최대 강수확률을 표시합니다. 지역별 실제 예보가 같으면 숫자가 같을 수 있습니다.
- API 주소 생성과 응답 해석은 `logic.js`, 호출과 화면 반영은 `app.js`가 맡습니다.
- 일정은 API 응답을 기다리지 않고 먼저 표시합니다. 실패하거나 10초를 넘긴 지역은 날씨 `-`, 판단 `날씨 확인 전`으로 남습니다. 실내는 날씨 수신 여부와 관계없이 `영향 없음`입니다.
- 판단은 실내 → 고소 강풍(10m/s 이상) → 폭염(33℃ 이상) → 우천(60% 이상) → 진행 순서로 하나만 표시합니다.
- API 항목과 단위는 [Open-Meteo 공식 문서](https://open-meteo.com/en/docs)를 따릅니다.

## 확인 방법
| 번호 | 절차와 기대 결과 |
|---|---|
| T-01 | 배포 주소에서 열면 JSON의 기본 일정 6건이 먼저, 이전에 추가한 일정이 그 뒤에 보입니다. 더블클릭 시 JSON을 읽지 못하면 `배포 주소로 열어 주세요`가 표시됩니다. |
| T-02 | 가상 일정을 추가하면 맨 아래에 보이고 새로고침해도 남습니다. 날씨가 수신된 지역은 새 일정에도 바로 반영됩니다. |
| T-03 | 인터넷에 연결해 열면 지역별 최고 기온 · 최대 풍속 · 최대 강수확률과 판단이 나타납니다. 같은 지역은 같은 값을 사용합니다. |
| T-04 | 브라우저 주소의 `index.html` 뒤에 `?test=wind`를 붙여 엽니다. 날씨 수신 후 풍속이 12m/s가 되고 기본 고소 일정 2건이 `중지 검토 (강풍)`로 표시됩니다. 시험 안내도 보입니다. |

추가 실패 확인: 개발자 도구의 요청 차단으로 Open-Meteo 요청만 차단하고 새로고침합니다. JSON 일정 목록과 일정 추가는 계속 사용할 수 있고, 실외 일정은 `날씨 확인 전`, 실내는 `영향 없음`으로 표시됩니다. 일부 지역만 실패하면 성공한 지역의 날씨는 계속 표시됩니다. `data/tasks.json` 요청 실패 시에는 파일 읽기 실패 안내와 브라우저에 저장된 추가 일정이 표시됩니다.

강풍 시험은 정상 수신한 날씨의 풍속만 바꿉니다. API 실패 시 가짜 기온이나 강수확률을 만들지 않으므로, T-04 확인에는 날씨 수신이 필요합니다. 시험을 마치면 주소에서 `?test=wind`를 지우고 다시 엽니다.
